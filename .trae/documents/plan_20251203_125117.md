# 通用SQL表结构设计方案

## 问题分析
1. **用户需求**：
   - 设计通用SQL语句，支持任意字段的JSON存储
   - 主要字段：`datainfos` (JSON类型)、`is_date` (更新时间)、`is_del` (逻辑删除)、`is_rols` (权限标识)
   - 支持前端任意字段的JSON编码存储
   - 支持权限控制（users/admin等）
   - 支持逻辑删除
   - 自动更新时间戳

2. **当前状态**：
   - 已有迁移文件，但结构不符合通用设计要求
   - 需要修改为单一通用表或多表通用结构
   - 需要支持JSON数据存储

### 2. 设计通用表结构

```sql
-- 通用数据表结构
CREATE TABLE IF NOT EXISTS common_data (
    id SERIAL PRIMARY KEY,                      -- 主键ID
    table_name VARCHAR(255) NOT NULL,           -- 表名，用于区分不同类型的数据
    datainfos JSONB NOT NULL DEFAULT '{}'::jsonb, -- 通用JSON数据存储
    is_rols VARCHAR(50) DEFAULT 'users',        -- 权限标识
    is_del BOOLEAN DEFAULT FALSE,               -- 逻辑删除
    is_date TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP, -- 更新时间
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP, -- 创建时间
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP -- 实际更新时间
);

-- 索引设计
CREATE INDEX IF NOT EXISTS idx_common_data_table_name ON common_data(table_name);
CREATE INDEX IF NOT EXISTS idx_common_data_is_del ON common_data(is_del);
CREATE INDEX IF NOT EXISTS idx_common_data_is_rols ON common_data(is_rols);
CREATE INDEX IF NOT EXISTS idx_common_data_datainfos ON common_data USING GIN(datainfos);

-- 自动更新触发器
CREATE OR REPLACE FUNCTION update_is_date()
RETURNS TRIGGER AS $$
BEGIN
    NEW.is_date = CURRENT_TIMESTAMP;
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_common_data_is_date
BEFORE UPDATE ON common_data
FOR EACH ROW
EXECUTE FUNCTION update_is_date();
```

### 3. 实现效果

1. **通用数据存储**：
   - 前端可以将任意字段编码为JSON，存入`datainfos`字段
   - 支持动态字段扩展，无需修改表结构
   - 支持JSON查询和索引

2. **权限控制**：
   - 通过`is_rols`字段实现简单的权限控制
   - 支持users、admin等权限标识

3. **逻辑删除**：
   - 通过`is_del`字段实现逻辑删除
   - 保留数据完整性，便于恢复

4. **自动更新时间**：
   - `is_date`字段自动记录更新时间
   - 无需手动维护

5. **高性能设计**：
   - 合理的索引设计，提高查询性能
   - 支持JSONB类型，适合存储半结构化数据

### 4. 使用示例

#### 写入数据
```sql
INSERT INTO common_data (table_name, datainfos, is_rols)
VALUES (
    'users', 
    '{"username": "test", "email": "test@example.com", "password": "hashed_password"}'::jsonb,
    'users'
);
```

#### 更新数据
```sql
UPDATE common_data 
SET datainfos = '{"username": "test_updated", "email": "test@example.com", "password": "new_hashed_password"}'::jsonb
WHERE id = 1;
```

#### 逻辑删除
```sql
UPDATE common_data 
SET is_del = true 
WHERE id = 1;
```

#### 查询数据
```sql
SELECT id, table_name, datainfos, is_rols, is_date 
FROM common_data 
WHERE table_name = 'users' AND is_del = false;
```

## 技术要点

1. **JSONB类型**：
   - 使用PostgreSQL的JSONB类型，支持高效的JSON存储和查询
   - 支持GIN索引，提高JSON字段的查询性能

2. **自动触发器**：
   - 使用PostgreSQL触发器自动更新时间戳
   - 确保数据一致性

3. **逻辑删除**：
   - 避免物理删除，保留数据完整性
   - 便于数据恢复和审计

4. **权限设计**：
   - 简单的权限标识，适合通用场景
   - 支持扩展到更复杂的权限系统
