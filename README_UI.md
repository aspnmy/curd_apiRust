# CRUD API 测试UI

## 功能描述

这是一个用于测试CRUD API的前端UI组件，支持图片上传、列表展示、详情查看、修改和删除功能。

## 文件结构

```
ui/
├── index.html      # 主页面
├── styles.css      # 样式文件
└── app.js          # JavaScript逻辑
```

## 使用方法

### 1. 启动后端API服务

首先，确保您的CRUD API服务已经启动，并且可以通过以下地址访问：

```
http://localhost:8000
```

### 2. 测试UI组件

#### 方法一：直接在浏览器中打开

您可以直接在浏览器中打开 `index.html` 文件进行测试。但请注意，由于浏览器的同源策略限制，可能会出现跨域问题。

#### 方法二：使用本地HTTP服务器

推荐使用本地HTTP服务器来测试UI组件，这样可以避免跨域问题。

**使用Python 3：**
```bash
# 进入ui目录
cd ui
# 启动HTTP服务器
python -m http.server 3000
```

然后在浏览器中访问：
```
http://localhost:3000
```

**使用Node.js（需要安装http-server）：**
```bash
# 全局安装http-server
npm install -g http-server
# 进入ui目录
cd ui
# 启动HTTP服务器
http-server -p 3000
```

然后在浏览器中访问：
```
http://localhost:3000
```

### 3. 配置API地址

如果您的API服务运行在不同的地址或端口上，您可以修改 `config.js` 文件中的 `API_BASE_URL` 变量：

```javascript
const UI_CONFIG = {
    // API基础URL
    API_BASE_URL: 'http://your-api-address:port/api'
};
```

这样可以避免直接修改 `app.js` 文件造成的格式异常错误。

## 功能说明

### 1. 图片上传

- 点击"选择文件"按钮选择要上传的图片
- 图片会自动生成预览
- 点击"上传图片"按钮将图片上传到服务器

### 2. 图片列表

- 自动加载图片列表
- 支持搜索图片
- 支持显示所有数据（包括已删除）
- 支持刷新列表

### 3. 图片详情

- 点击图片或"详情"按钮查看图片详情
- 显示图片的完整信息，包括名称、类型、大小、描述等

### 4. 图片修改

- 点击"修改"按钮进入编辑模式
- 可以修改图片的名称、类型、描述和内容
- 点击"保存修改"按钮保存更改

### 5. 图片删除

- 点击"标记删除"按钮将图片标记为已删除
- 点击"真实删除"按钮彻底删除图片（仅对已标记删除的图片可见）

## 技术说明

- 纯前端实现，使用HTML、CSS和原生JavaScript
- 调用现有的CRUD API端点
- 支持图片预览和Base64编码
- 响应式设计，适配不同屏幕尺寸

## 注意事项

- 本UI组件仅用于测试目的，不建议在生产环境中使用
- 确保您的API服务已经正确配置，允许跨域请求（如果需要）
- 测试完成后，请关闭相关服务，以避免安全风险
